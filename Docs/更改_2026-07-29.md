# wave1 · C1 T1 水毁跨 session 锁存（湿度极值）

## 为什么改

洪水泡透的土堆会塌成湿泥——这是"不可逆"的承诺（宪法③）。但之前有个漏洞：
如果你在水毁发生后、湿度自然回落的间隙离开游戏，下次回来时土堆会悄悄"复原"成完好形态。
原因是锁存判定看的是"现在还湿不湿"，而不是"曾经湿没湿过"。
本批给每个地区记一个**历史湿度极值**（只增不减），水毁改判极值——
水退可以，但"这里曾经泡透过"这件事，世界会一直记得。

## 玩家会看到什么

被水泡塌的土堆，永远保持塌掉的形态。不会再出现"过两天回来看，它又鼓起来了"。
