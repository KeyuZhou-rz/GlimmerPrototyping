# Demo 收口——最小可玩闭环

## 为什么改

此前世界已经会自己活（预跑 30 天、天气、痕迹、世界志、缺席信全链路都在），
但玩家只能站在外面看：没有地方写日记，信和痕迹的入口没有任何提示，
而且场景里留着一个研究者用的情绪注入器，每帧往世界里灌中性情绪——
真玩家写的东西会被它立刻冲掉。

本批把玩家侧半边接上：写日记的地方有了，入口提示有了，污染情绪的注入器拆了，
并产出第一个可分发的 Windows 构建。

## 玩家会看到什么

- 左上角多了一行淡小提示："J 写日记 · 点亮斑细看 · L 读信"。
- 按 J 出现一个素面板，写点什么，Ctrl+Enter（或点提交）发出去——
  一句"世界收到了。"淡淡隐去。写"难过"，当天天色就会转阴（情绪脉冲快通道）；
  更慢的变化（草色、动物、痕迹）随后几天显形。
- 信或日记面板开着时，点击不会再穿透到场景把相机推走。
- 世界自己的情绪不再被每帧冲刷：你写的情绪会以月为单位慢慢沉淀（情绪有惯性，是设计）。

# A 方案 + 延迟消化 + 触感层第一批

## 为什么改

两个手感问题：①世界演化的节奏被日记驱动了——写一篇就"当场多演一天"，
世界变成了输入的反应器，违背"世界有自己的生命"；②短会话太静——
刚打开写一句话就关掉的几分钟里，世界几乎没有活的迹象。

本批：世界回到只在日历日边界演化；日记的天气回响不再秒到，
世界会先"想一会儿"（2-4 分钟）才转阴/起风；草海变成可以触摸的——
点哪哪簌动，风大时偶有阵风滚过整片草海。

## 玩家会看到什么

- 写完日记，天色不再立刻应答。过两三分钟，世界"想完了"，天气才转。
  关掉 app 也不丢——下次打开时世界已经想完了（回响在你缺席时落地又散去）。
- 动物、痕迹、世界志的后果不再是写完就结：它们隔天才浮现（世界的故事按自己的日历走）。
- 点草海任意一处：那圈草朝外颤动一阵（约 2 秒）。配簌簌声的素材位已留好（见下）。
- 起风的日子里，偶尔能看到一道风带从草海一端滚到另一端。
