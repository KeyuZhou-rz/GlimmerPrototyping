# 更改 2026-08-03

# Demo 收口——最小可玩闭环

## 为什么改

此前世界已经会自己活（预跑 30 天、天气、痕迹、世界志、缺席信全链路都在），
但玩家只能站在外面看：没有地方写日记，信和痕迹的入口没有任何提示，
而且场景里留着一个研究者用的情绪注入器，每帧往世界里灌中性情绪——
真玩家写的东西会被它立刻冲掉。

本批把玩家侧半边接上：写日记的地方有了，入口提示有了，污染情绪的注入器拆了，
并产出第一个可分发的 Windows 构建。

## 玩家会看到什么

- 左上角多了一行淡小提示："J 写日记 · 点亮斑细看 · L 读信"。
- 按 J 出现一个素面板，写点什么，Ctrl+Enter（或点提交）发出去——
  一句"世界收到了。"淡淡隐去。写"难过"，当天天色就会转阴（情绪脉冲快通道）；
  更慢的变化（草色、动物、痕迹）随后几天显形。
- 信或日记面板开着时，点击不会再穿透到场景把相机推走。
- 世界自己的情绪不再被每帧冲刷：你写的情绪会以月为单位慢慢沉淀（情绪有惯性，是设计）。

## 留用户验收（exe 手感清单）

1. 双击 `Builds/Windows/Glimmer_Prototyping.exe`：首屏草原 + 左上角提示行可读
2. 按 J 写一句"今天有点难过"，Ctrl+Enter：面板合上、"世界收到了。"淡出、当天天色随后转阴
3. 点草里橙色亮斑：相机推近+一句观察语料；按 L 开信时点面板区域相机不动
4. 退出重进：世界还在；改天再来：收到"你离开的这些天——"缺席信
5. 夜晚启动一次：星空/月相（月相如今随世界历圆缺）
