# 更改记录 2026-08-13

## 批次三（V1 D5+D6）：新生地层——沉降、出露、记忆双读

### 为什么改（玩家视角）

- **旧痕迹不再凭空消失，而是沉进土里**：以前土堆太多时最老的会被"剪掉"。
  现在它会先塌成一小片旧迹（还能点，语气是"它们住过这里"），再慢慢沉成
  地表上一点几乎看不出的土色异样——存在过的东西只是沉下去了，没有被删掉。
  塌洞也从出生那天起就踏上这条路：永远留下，但会一年年往下沉。
- **沉下去的速度看世界怎么过日子**：风大的年份沙埋得快，雨多的年份泥盖得快，
  草盛的地方根缠得快。埋得深不深，本身就是那几年的记录。
- **沉底的东西偶尔会被翻出来**：风暴夜（激烈情绪之后）可能把旧物剥出地表；
  田鼠在附近打新洞，也可能把隔壁的旧东西翻上来。重见天日的那件会半埋在原地，
  当天会有一个注意标记指给你看——旧物回来了，这是新闻。
- **同一件旧迹，见证过它和没见证过的人，读到的不是同一句话**：
  它发生时你在场（在线看到，或后来读信知道了它），点它时说的是
  "这堆土你见过的——镇子还在的时候。如今沉下去半截了"；
  它属于你错过的年代，说的就是"一处旧迹。比你早"。
  每句都带着它入土时的年代感——那年代由世界翻过几页来定，不由时钟来定。

## 点击失灵根因修复（批次二挂号项，D9 前置清除）

### 为什么改（玩家视角）

- **点世界的点击全部恢复了**：点草地草会簌动，点痕迹/亮斑会推近出观察语。
  之前点哪都没反应，不是点击坏了，是"别点穿 UI"的保护闸门认错了人——
  它把整片草原当成了一块 UI 面板，替你"挡住"了每一次点击。

### 根因（实证链）

1. 主相机上挂着一个场景模板遗迹 `PhysicsRaycaster`（PlantGrowthTemplate.unity:12114，
   事件掩码=全层），全项目无任何消费者——但没有 EventSystem 时它完全无害，躺了很多周。
2. 08-03 demo 收口（768ba20）运行时自建 EventSystem + InputSystemUIInputModule（日记 UI 需要），
   `TraceInput` 的闸门① `IsPointerOverGameObject()` 从此刻起才真正生效
   （此前 `EventSystem.current == null` 恒短路 false——这就是"之前一直正常"的原因；
   08-03~08-12 三批验证全走键盘快进+批处理冒烟，无人点击，故迟至 08-12 暴露）。
3. 新输入模块把"指针射线打到的第一个物体"直接记为 `pointerEnter`（InputSystemUIInputModule.cs:528），
   **不过滤是否 UI**；`IsPointerOverGameObject()` 只查 `pointerEnter != null`（同文件:322）。
   PhysicsRaycaster mask=全层 → 悬停地形/痕迹恒有命中 → 闸门①吞掉一切世界点击。
4. 唯一能过闸门的点击是点天空（无碰撞体）→ 随后真的什么都没打到，
   报"射线未命中任何碰撞体"。两个症状，一个病。

### 改动清单

| 文件 | 改动 |
|---|---|
| `Assets/Script/TraceInput.cs` | 闸门①改为 `PointerOverUGUI`：`EventSystem.RaycastAll` 后只认 `GraphicRaycaster` 命中（当前项目无任何 GraphicRaycaster → 恒 false，信/日记防穿透由闸门② IsOpen 兜底；未来接入可点击 uGUI 时自动生效）。排查日志按 9194b03 约定全部清除 |

### 验证

- 离线编译 0 错误；play 实测（2026-08-13 用户确认）：点草簌动 ✓、点痕迹/亮斑推近+语料 ✓、
  信开着点世界不穿透、关信恢复 ✓。

### 遗留雷（已挂号，未动）

- 主相机 PhysicsRaycaster 仍在场景里（mask=全层）。本次修复后它不再影响点击，
  但任何未来的 `IsPointerOverGameObject` 调用都会踩同一个坑——建议择机在 Inspector 移除并存场景
  （场景手工组件删除，未由 Claude 代劳）。

## 批次四（V1 D7+D8）：侧翼——慢变量骨架 + 河/路/风三通道

### 为什么改（玩家视角）

- **世界比你看到的大**：舞台之外的两端——西边的草原/上游、东边的高地/下游——
  现在有自己的天气和族群日子。它们永远不可抵达、没有地图、看不到实体，
  但那边发生的事会顺着三条通道漏进你这一页：
- **河**：西边的雨季夜里下雨，水一两天后才流到你这里——
  你这里一滴雨没下，河水却涨了。信会告诉你"水是从西边来的"。
- **路**：西缘有时出现一串你没见过的脚印，一天比一天走得更深，十二天后淡掉；
  你的动物离开时，东缘会留下一串往山里去、几星期才淡完的印子；
  偶尔有连夜赶路的过路客，脚印两三天横穿整个舞台，不停留。
- **风**：西边大旱时，你能看见地平线挂上一层尘霾——晴天也挂着。
  你还没读信，不知道它意味着什么；一个月后信里说"西边的雨季没有来"，你才想起来那片霾。
- **侧翼的消息永远迟到**：水迟一两天，信迟一个月。信息以动物的速度旅行，所以世界显得辽阔。
