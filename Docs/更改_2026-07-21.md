# 更改 2026-07-21：缺席信 + 规则冷却持久化（Batch 1）

> 依据：`Docs/交互设计工作台_2026-07-21_矩阵补全.md` §5.5 第 1 行（缺席信，后续优先级 1）+ §5 末尾横切注记（规则冷却进存档）。
> 实施：Claude，auto mode。

## 为什么改

1. **缺席的日子被扔掉了**：catch-up 期间产生的世界志被整段删除（`WorldManager.cs` 原 189-197 行），玩家回来对缺席期发生的事毫无交代。改为：按 salience 取 ≤5 条合成一封"缺席信"，信末点名窗口内新增的永久痕迹，引玩家去现场确认。
2. **规则冷却重启清零**：冷却存内存字典，关游戏即忘，久未登录会立即重触发（如田鼠洪水搬家 14 天冷却失效）。改为：冷却记录进存档，跨 session 存活。

## salience 分级表

| 级别 | 类别 | eventId 判定 |
|---|---|---|
| 3 | 永久事件 | `baobab_branch_broken`、`vole_burrow_abandoned`、`event_TreeBranchBroke` |
| 2 | 迁移/到离场/涌现 | `vole_relocate_flood`、`migratory_bird_arrival`、`event_AnimalArrived/AnimalDeparted`、`event_WeaverBirdDeparted/WeaverBirdReturned`、`event_QuietConvergence` |
| 1 | 天气极值 | `behavior_` 且含 `Harsh` |
| 0 | 日常噪音 | 其余（不进信） |

## 边界

- 缺席 > 90 天：信只覆盖重模拟的最后 90 天（软上限不变）
- 新世界 30 天预跑：不产生信（玩家尚未到达）
- 整段无 ≥1 级条目：不生成信（不塞"什么也没发生"的噪音）

## 验证

1. 离线编译零错
2. 改 `lastTickRealTime` 为 N 天前 → play → L 键：首封缺席信 ≤5 条、高级别在前、有永久事件则信末点名；save 里该段噪音已删、只留一封信
3. 平静 1 天 → 无信
4. 删存档开新世界 → 预跑后无 absence_letter
5. 规则触发后退出重开 → `world_state.json` 有 `ruleCooldowns`，冷却期内不重触发
