## 视觉基调

北星像（非洲稀树草原之夜）的天空不是摄影天空，而是**画在岩壁上的天空**——
借桑人（San）岩画的材料语言：赭石、木炭、骨白、蛋彩，画面是矿物颜料沁进
岩面的效果。天空 = 世界这幅「活岩画」的底壁。

三条材料规则（所有天空视觉判断的依据）：

1. **雕刻而非光学** —— 太阳是凿进岩壁再填彩的日轮图腾（离散刻画元素：
   刻环、断续弧、短射线、凿痕暗边），不做镜头光晕/大气散射/连续径向渐变。
   连续光晕数学在图腾化精修轮已废除。
2. **岩面而非真空** —— 天空有极轻的岩壁颗粒和矿物斑驳（白天 2-3% 亮度扰动，
   功能是消色带 + 承接岩画气质；不能明显到偏离 demo.jpg 的干净渐变）。
   次序：斑驳 → 图腾填彩 → 细颗粒（颜料盖在风化岩面上，岩齿透过颜料）。
3. **传说而非星表** —— 夜空是 ǀXam 传说「少女掷灰成河」的银河：
   点描撒灰带（手点的灰烬颗粒非连续雾，30% 薄雾垫底）+ 炭黑暗裂谷纵贯
   + 骨白/赭红双色星点（赭红余烬 ~14%），不用照片感星云 cubemap
   （星云贴图弃用，留盘不删）。

## 复杂度边界（本轮明确不做）

  世界自己的生命，与用户输入无关（原则 1）。

## TLD/KRZ 完成度轮（2026-07-12）

风格化天空的"完成感"来自四件事，全部落地：

1. **四相独立色板**（不再是单一色板×乘法压暗）：白天（尘蓝苍白）/黄昏（青板岩-尘玫瑰-琥珀）/夜（深海军+airglow 暖灰地平微光）/暴雨，每相 zenith/mid/glow 三停；相位权重由真实太阳仰角 smoothstep 导出（wNight/wGold/wDay），控制器逐帧混合后写入。
2. **四停垂直渐变**：雾线(0~3%)→地平辉带(→14%)→中天(→50%)→天顶。雾线永远=雾色（远山溶解锚，色带量化不许碰）。
3. **日侧/背日侧方位不对称**（TLD 核心）：辉带与中天色都按 `pow(azim,1.6)` 向日侧集中，背日侧收敛向冷色（`lerp(_SkyMid,_SkyZenith,0.6)`）；日侧再叠 `_SunWashCol` 暖洗（黄昏 0.45 / 白天 0.15 / 夜·暴雨 0）。黄昏 = 日侧琥珀拉满、背日侧灰玫瑰冷沉。
4. **中度色带 + 笔触**：每停局部 t 量化（3/4/4 段）+ IGN 屏幕抖动，`_BandingAmount 0.55`（storm 相自动减半防等值线）；斑驳换水平拉长两八度卷云笔触（`float3(1.3,6.0,1.3)` 各向异性），强度相位驱动（day .05/golden .10/night .02/storm .16）。

夜雾同步换色相：`nightFogColor (0.095,0.11,0.145)` 海军灰 lerp 取代旧乘法压暗（夜雾不再是棕灰）。

## 数据流（单写者纪律）

```
WorldAtmosphereBinder (L3绑定层，只读世界状态)
    └─> EmotionWeatherController.rainIntensity / dimness
            └─> UpdateRain()    → 雾距/雾色（含昼夜压暗）→ _fogColThisFrame
            └─> UpdateSkybox()  → SkyGradient.mat 全部运行时属性（唯一写者）
                  _SkyTop/_GroundCol : sunny↔storm 按 badT 混合 × nightMul
                  _SkyHorizon        : = 本帧雾色 → 远山溶进天空（demo 核心）
                  _SunDir            : 每帧从真实太阳读方向（昼夜自动走）
                  _SunGlow/_SunDiscStrength : 坏天气收晕、日盘隐入云层
                  _StarBlend         : (1-dayLight) × (1-badT×stormStarHide)
LightManager: 只管平行光颜色/旋转 + ambientLight，不碰天空盒
```

- badT = `clamp01(smoothedRainIntensity + dimness×dimnessFogWeight)`，与雾公式同源
  —— 天和雾必须一起变脏，否则天地脱节。
- 星空被情绪调制的路径：坏天气(E_env→雨/晦明)→badT→星减；这是「天气遮蔽」
  而非「情绪直连」，符合层边界（Layer 3 只读 E_env 的间接产物）。

## 关键实现注记

- **Hash 选型**：方向域高频采样必须用 Hoskins 乘加 hash（`Hash13/Hash33`），
  sin-hash 会出平台相关条纹。
- **星点单格采样**：特征点缩在格心 0.2~0.8、半径≤0.15 格 → 星不会跨格被裁，
  省掉 27 邻格查询。
- **风化遮罩**：颗粒/斑驳在 |y|<0.015 处淡出 → 地平线带保持纯雾色，
  远山溶解不被颗粒打断。
- **编辑态=运行时**：`GlimmerVisualSetup.PreviewSky` 与 `UpdateSkybox` 同一套
  映射；进 Play 由控制器接管。SetupSky 幂等，sky.mat（星云版）留盘备份。

## 残阳轮（2026-07-18 设计者修订）

**触发**：用户给出残阳参考图（`Assets/Screenshot 2026-07-18 184700.png`：沉日半入
地平线、白热日盘嵌入宽幅橙粉辉带、上天空灰紫、大象与树剪影），指出 skybox 没有
"太阳晕染出来"的效果，要求日出/日落两个时段着重打磨。

**决议修订（覆盖 07-12 的一条）**：材料规则 1「雕刻而非光学」中"废除连续光晕"
修订为——**光晕回归，但必须走岩画色带语言（BandT 量化 + IGN 抖动），不做摄影级
径向渐变**。图腾刻画语言不变；晕染是颜料色带，不是镜头光晕。

**取景决议（rig 物理约束，二答拍板）**：昼夜 rig 太阳绕 yaw=170° 轴旋转，
升/落点对趾——日出太阳在**北**（主相机画内），日落太阳在**南**（镜头背后）。
拍板"保 rig"：日出入画拿可见沉日；日落在北天做**反日余晖**（维纳斯带 + 地影），
不翻转 rig。

### 残阳晕染元素表（shader §1c，全部过 BandT 色带量化）

| 元素 | 几何（y=天穹高度） | 颜色 | 备注 |
|---|---|---|---|
| 白热核 haloCore | y∈[0,0.10]，azim⁶ 窄聚日侧 | _HaloCol×1.35+暖白偏移 | 沉日的白热本体 |
| 珊瑚宽带 haloBand | y∈[0.02,0.40]，azim²·⁵ 宽展 | _HaloCol (1.0,0.48,0.28) | 水平展宽竖向压缩，参考图辉带 |
| 维纳斯带 antiBand | y∈[0.03,0.24]，(1-azim)² 反日侧 | _AntiGlowCol (0.80,0.42,0.52) | 粉紫余晖拱 |
| 地影 earthShadow | y∈[0.015,0.05] 反日侧 | (0.38,0.40,0.52) 蓝灰 ×0.7 | 地球投进大气的影子；避 y<0.015 雾线锚 |

点燃条件：`elevMask = 1-smoothstep(0.015,0.22,|sunDir.y|)`——只贴地平线才燃；
太阳略沉地平面下仍有余晖（不吃 sunUpMask）；坏天气 ×(1-badT) 熄灭。
控制器驱动：`_HaloAmt = elevMask×(0.30+0.70×wGold)×haloStrength×(1-badT)`，
`_AntiGlowAmt = elevMask×antiGlowStrength×(1-badT)`（haloStrength 0.90 / anti 0.65）。

### 图腾低日角姿态（shader §3 修订）

- **刻环/射线收敛**：`ringStr ×= (1-lowSun×0.65)` —— 低日角时 14° 跨度的骨白刻环
  退隐，图腾退成白热核，否则读作徽章不读作沉日。
- **地平线遮挡 hOcc**：`smoothstep(-0.005,0.015,y)` 乘到盘/环/射线/凿痕 ——
  日盘下半被地平线吃掉（残阳的"残"字本体），不再整盘悬在雾线上。
- **_SunTint 白热化**：控制器 `lerp(sunTintDay(1,0.72,0.42), sunTintLow(1,0.88,0.70), elevMask)`。
