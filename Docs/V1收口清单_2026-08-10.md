## 4. 长程设计定稿（本阶段实现规格）

### 4.1 droughtDebt（工作台 §5.5 优先级 2）
- 每 tick `+= max(0, 季节基准雨 − Rainfall)×k`；下雨扣减。
- 双阈值：＞0.3 植被衰败加速；＞0.6 动物向 riverbank 收敛＋树恢复停滞。
- 只接已有下游（水位、动物、信），不接任何新视觉。

### 4.2 纪元钟（事件驱动的章节机）
- 不看表，只看累积状态；章节可倒退，循环坐庄，不是线性升级。

| 章节 | 进入条件（全部读已有状态） |
|---|---|
| 荒年 | droughtDebt＞0.6（或世界初始态） |
| 雨季/丰年 | 连续 N tick Rainfall 高于季节基准，droughtDebt＜0.3 |
| 定居 | 丰年持续 ∧ 田鼠在 lowland/center 连续在场 M 天 ∧ 土堆活跃数 ≥ k |
| 镇 | 见 §4.3 阈值 |
| 衰 | 洪水（lowland 水位＞0.65，与田鼠搬家规则同源）或 droughtDebt＞0.6 持续 |

- 每次转换 → 一封**编年史信**。没有横幅，没有"进入新时代"。

### 4.3 田鼠镇（部落化 ×1）
> 红线：**文明的复杂度加在痕迹的语法上，不加在动物的 AI 上。文明是被讲述出来的，不是被计算出来的。**

- 田鼠 AI 一行不动。
- 痕迹升级：lowland/center 土堆活跃数 ≥5 → 土堆之间生成**小径**（压草连线，复用草压痕通路）；小径固定化、日日重现。
- 措辞升级：信的称谓随密度漂移——"一只田鼠"→"它们"→"镇子"。
- 衰落：洪水/大旱 → 镇散 → 小径停止重现，旧小径按痕迹寿命淡出；塌洞照旧永久（不可逆原则）。
- 保留误读空间：信可能把一群动物讲成一个部落——误读即魅力（验收三问③）。

### 4.4 缺席信（回归循环的全部机制）
- catch-up 摘要：salience 排序（**永久事件＞物种迁移＞天气极值**）取 ≤5 条。
- 可**点名永久痕迹**（"东侧低地多了一个塌洞"），引导现场确认。
- 跨越章节转换的缺席 → 缺席信升级为编年史章节语气。

### 4.5 新生地层（完整版——从存档归队，本阶段实装）
> 不是新系统，是现有痕迹寿命曲线的延长：持久型痕迹不再以"删除"为终点，而以"沉降"为终点。

**沉降三阶段：**

| 阶段 | 状态 | 玩家读到 |
|---|---|---|
| 现役 | 现有痕迹系统，一字不动 | 新鲜的故事 |
| 遗存 | 寿命到期不删除：塌矮、色变沉、草漫上（全靠现有 prefab 的 scale/tint/下沉参数，不加新美术） | 旧迹语气："这是去年的东西了" |
| 地层 | 沉入地表之下，只剩一点硬度与草色的异样 | 几乎不可读——直到出露 |

- **沉降率**：风大沙埋快、雨多泥盖快、草盛根缠快——**埋藏的深度本身就是记录**（埋得深＝那几年风大）。
- **封闭层**：纪元每次翻页，在大地上盖一层封印。本阶段为**数据锚**（地层断代依据）＋一条语料，不做视觉层。**纪元钟的每次翻页，都在大地上盖一层封印——地层之间的分界线，就是你的章节号。**
- **出露两法**（河岸剖面不做）：风暴剥蚀（A＞0.7 风暴夜后概率出露）；田鼠翻土（田鼠在半径内打洞时概率翻出旧物）。
- **记忆双读**（情感核心）：
  - 见证过它的诞生（在场，或信里记过）→ **记忆语气**："它们住过这里。那时你刚来。"
  - 未见证（预演期、错过的章节）→ **考古语气**："比那棵死树老，比这条河年轻。"
  - 同一个对象，读法由玩家的传记决定。**世界不只知道自己的历史，它知道你参与了哪一段。你目击过的东西，在你眼前变成文物。**
- 实现：每个永久事件存 `witnessed` 标记（发生时被目击 ∨ 被已读信件点名）；出露时按标记选语域。
- **预算**：只有持久型痕迹进入沉降（脚印、羽毛照旧速朽）；每区地层对象设上限；老的继续下沉、降分辨率、不删档。**地层越深，细节越少，语气越古。**

### 4.6 深层遗迹（只做"认出"）
- 四种各一件：**岩棚画／石环／石器散布／磨盘石**，最简视觉（半埋静态件）。
- 显现共用 §4.5 两种钩子：**田鼠翻土＋风暴剥蚀**。
- 交互：点击 → 推近 → 小报语料。**不做挖掘、不做进度、不做收集册。**
- 深层遗迹恒用考古语气（记忆双读只服务新生地层）。
- 语料给推断不给答案："比那棵树老。比这条河年轻。"

## 5. 侧翼设计定稿（本阶段实现规格）

> 侧翼是舞台边界之外的世界。不是地图、不是场景、永远不可抵达。
> 戏剧里的"侧翼"：演员从那里上场，观众永远看不见侧翼里面。

- **两翼先开**：西（草原/上游方向：来水、来风、来者）与东（高地/下游方向：去处、尘霾、远行）——正好接现有拓扑 riverbank→…→highland_east 的两端，一管"来"一管"去"。南北留档。
- **每翼只持 2～3 个慢变量**（西侧：旱涝状态、族群压力；东侧：旱情烈度）。无实体、无个体模拟、无地图。周粒度漂移＋事件掷签。
- **三条通道**：
  - **河（D7 优先）**：上游夜雨 → 1～2 日延迟 → riverbank 水位异动。"你这里一滴雨没下——上游在下雨。"**河本来就是一条现成的侧翼通道，它夜夜给你写信。**
  - **路（D8）**：新物种痕迹自西缘出现、数日蔓延入五区；你的动物自东缘离去、领地标记数周淡出。
  - **风（D8 最简）**：西侧旱情以**地平线尘霾**被看见（天空/雾参数级，不做新美术）。
- **延迟即诗学**：侧翼的消息永远迟到。信里说"一个月前，西边的雨季没有来"——你这才明白上周河岸那些陌生脚印是谁的。信息以动物的速度旅行，所以侧翼显得辽阔。
- **过路客**："你没见过的脚印，从西边的草里来，到东边的山里去。它们没打算留下。"过客痕迹链 2～3 日横穿舞台，不进驱力系统、不停留。
- **接口**：纪元章节触发条件可读侧翼变量（如"西旱"章节）。
- **红线：侧翼永远只是侧翼。**不可解锁、不可放大、不可前往、永远没有小地图。**世界比你看到的大，而你永远只能看到这一页。**

## 8. Demo 演示剧本（15 分钟加速路径）

> 用 D1 的快进开关，把三个循环压缩进一次演示。每一拍对应一个 D 项，走不通就回查那一天。

1. **荒年开局**：预演世界，地平线西侧挂着尘霾（D8）——你还没读信，不知道这意味着什么。
2. **写日记**（日循环）：世界在随后几天里以雨量回应。
3. **快进**：雨季信抵达（D2 纪元转换）；河岸水位上涨——但你这里没下雨（D7 上游夜雨）。
4. **快进**：田鼠定居 → 土堆连线 → 镇成形，信改口称"它们""镇子"（D3）。
5. **快进**：大旱/洪水 → 镇散，小径淡出，塌洞留下（D3 衰章）。
6. **快进**：旧镇沉降为遗存、入地层（D5）；一场风暴夜后，出露（D6）。
7. **认出**：点击 → 推近 → 因为你见证过全程，语料是记忆语气："它们住过这里。那时你刚来。"（D6 记忆双读——demo 的情感高潮）
8. **侧翼收尾**：西缘出现你没见过的脚印，向东去（D8 过路客）；信解释了一个月前的西旱（D7 延迟）。
9. **深时间**：田鼠翻出一枚石片 → 点击 → 小报语气（D9）。

## 9. 验收

**持久化验收**：杀进程、过三天、重开——纪元、镇史、地层、信件、冷却，全部还在。

**V1 验收五问**：
1. 第三天早晨，你是"惦记"还是"该测试了"？
2. 不看代码，能指着一处痕迹讲出三环以上的来历吗？
3. 写的日记，你信不信世界真的读了？
4. 离开三天回来，有没有一处变化让你站住了？
5. 两个月后，这片土地有没有一段你能讲给别人听的"历史"？

**Demo 验收**：§8 剧本一次走通，九个拍子每拍都有屏幕上可见的东西。
