# 更改 2026-07-23：蒲公英风絮落种（§5.3）＋ 植被捂水（§5.5 第 3 行）（Batch 3）

> 依据：`Docs/交互设计工作台_2026-07-21_矩阵补全.md` §5.3（风的实体化，2026-07-21 设计入档）＋ §5.5 第 3 行（植被→水保持，后续优先级 3）。
> 实施：前序会话经 Unity MCP 落地代码与场景；本轮做文档回写、离线编译复核与提交。

## 为什么改

1. **风不可见**：WindSpeed 早已在模拟里起伏，但玩家在场景里看不到"风"这个东西。矩阵定稿：蒲公英＝风向指示器——风峰日絮从河岸往下风飘；下风区湿度合适时，几日后冒出新绒苗。
2. **生命→环境没有反向线**：矩阵里所有耦合都是环境→生命。§5.5 第 3 行定稿第一条反向耦合：植被茂密的地方水退得慢（排水 −ε×veg、渗透 +δ×veg）。

## 玩家视角

起大风的日子，能看见一团团绒絮从河岸往低洼飘；几天后下风的低洼冒出星星点点的绒白小苗，过些日子又长进草里不见了。大雨过后，石头边的地早就干透，草密的低洼却还汪着水——世界志里会写"草把水喝住了"，但没人告诉你为什么。

## 边界与纪律

- 下风区由拓扑唯一确定（riverbank 唯一邻居 lowland），模拟层不引入风向概念；多风向区再议属设计决策
- L2 落种与 L3 絮飘读同一 WindSpeed 但互不依赖——低洼太干不落种时絮照飘："风把絮吹走了，什么也没留下"也是可读的
- 数值均为矩阵未给的初值（风峰 0.7／冷却 5 天／湿度门 0.4／ε=0.015／δ=0.05／苗龄 4+15 天），待 playtest 调
- 绒苗默认限期 15 日撤出；永久苗属设计拍板
- 捂水语料写"水退得慢"这件事，草是暗示，不点破机制
- ⚠️ **调试残留（非本批内容）**：`EmotionWeatherController` 里按存档算 moonPhase 的代码被注释，多出一行 `SetFloat("_MoonGLow", 1f)`（大写 L，属性不存在＝无效行），旁注"该地有一处会影响月亮的出现与否 可能是 skymaterial 先勿动"——是月亮显隐排查的中间状态，保留待续查
