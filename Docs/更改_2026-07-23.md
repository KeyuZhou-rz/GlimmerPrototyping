# 更改 2026-07-23：蒲公英风絮落种（§5.3）＋ 植被捂水（§5.5 第 3 行）（Batch 3）

> 依据：`Docs/交互设计工作台_2026-07-21_矩阵补全.md` §5.3（风的实体化，2026-07-21 设计入档）＋ §5.5 第 3 行（植被→水保持，后续优先级 3）。
> 实施：前序会话经 Unity MCP 落地代码与场景；本轮做文档回写、离线编译复核与提交。

## 为什么改

1. **风不可见**：WindSpeed 早已在模拟里起伏，但玩家在场景里看不到"风"这个东西。矩阵定稿：蒲公英＝风向指示器——风峰日絮从河岸往下风飘；下风区湿度合适时，几日后冒出新绒苗。
2. **生命→环境没有反向线**：矩阵里所有耦合都是环境→生命。§5.5 第 3 行定稿第一条反向耦合：植被茂密的地方水退得慢（排水 −ε×veg、渗透 +δ×veg）。

## 玩家视角

起大风的日子，能看见一团团绒絮从河岸往低洼飘；几天后下风的低洼冒出星星点点的绒白小苗，过些日子又长进草里不见了。大雨过后，石头边的地早就干透，草密的低洼却还汪着水——世界志里会写"草把水喝住了"，但没人告诉你为什么。

# 更改 2026-07-23（追加）：草色通路——湿度/季节/衰败 → 草色（Batch 4）

> 依据：`Docs/交互设计工作台_2026-07-21_矩阵补全.md` §5.5 第 4 行（草色三合一，后续优先级 4）＋ §5.3 石边草行（旱的指示器）＋ Batch 2 留给本批的「旱的枯黄」。
> 范围修订（设计者 2026-07-23）：**虫害斑块不做**（§5.3 虫害行维持"并入草色三合一"的挂起状态，本批不含）；只做 {DecayLevel, season, zone 湿度} → 草色一条视觉通路，顺带兑现旱枯黄与石边草雨量计。
> 实施：Claude，auto mode。

## 为什么改

1. **衰败度/季节在草地上不可读**：DecayLevel 天天在涨落、gameTime 四季轮转，但两万三千簇草一年四季一个色——世界最大的一块画布不讲话。矩阵定稿：GrassPreset 激活为唯一映射表，三个 B/C 级缺口一次闭合。
2. **旱的枯黄欠账**：Batch 2 做了地裂/水退/动物收敛，唯独「草黄」显式留给了本批。
3. **石边草是设计好的活雨量计**（少量雨快转绿、长期无雨最先枯黄），此前完全惰性。Batch 3 已让石头区土壤干得最快——本批把湿度接上颜色，雨量计自然成立。

## 玩家视角

下过雨，低洼的草先绿起来，石头边的草也跟着泛青；旱得久了，石头边的草最先发黄，接着整片草原慢慢枯下去。季节的轮转也写在草色上——雨季偏青、旱季偏金。玩家看到的是"这片地最近过得怎么样"，不是数值。

## 技术路线（一条通路）

```
L2（只读）                    L3 展示层                          渲染
loc.soilMoisture ×5 区 ─┐
env.DecayLevel ─────────┤   WorldAtmosphereBinder 读世界状态    Glimmer/Grass shader
env.DroughtDebt ────────┤ → 按 GrassPreset 映射表换算      →   vert: pivotWS 按 zone 锚点
rhythm.yearProgress ────┘   + 展示层平滑 → SetGlobal*           混湿度；frag 四级调色
                            （仿 _TramplePoints 全局数组先例）   湿度→季节→旱→衰败
```

- **zone 湿度逐簇混合**：shader 全局数组 `_GrassZoneAnchors[8]`（中心+半径）× `_GrassZoneMoisture[8]`，vert 里按簇心到各锚点距离加权混合——zone 交界处颜色自然过渡，无硬边。zone 外远距回落到全局 SoilMoisture。
- **石边草雨量计 = 映射曲线低端陡度**：石头区土壤干得快（Batch 3 已成），`moistureToGreen` 曲线低端做陡，0→0.15 的湿度差就能读出泛青——"24h 转绿"是展示层曲线兑现，**不改 L2 渗透表**。
- **旱枯黄**：droughtDebt 0.3→0.85 映射为枯黄混入量（阈值与 Batch 2 地裂同源 0.3 起）。
- **季节色**：yearProgress 连续混四季 tint（无硬切），与雨季节奏同向（夏湿偏青、冬干偏金）。

### 飘絮粒子已知问题（只记不修）

1. **位置错误**：`SetupSeedFluff()` 用 `WaterGenerator.transform.position` 做锚点，但 WaterGenerator 位置 (21.4, −8.9) 距离河岸区 zone 锚点 (−15.1, −8.9) 约 36m。粒子发射器不在河岸上方，主相机照不到。
2. **粒子太小**：startSize 0.05~0.1 世界单位（10cm），renderer maxParticleSize=0.5。在远景广角主相机上不到 1 像素。`claude_fluff.png` 能拍到 56 粒是因为专用临时相机离发射器仅 ~10m。
3. **forceOverLifetime 未在运行时更新**：Setup 硬写了力常量 X=0.329 / Z=0.082，但 `EmotionWeatherController.UpdateSeedFluff` 不覆盖 forceOverLifetime——粒子的风推力不随 WindSpeed 变化。

以上三条均不修代码，留待下轮飘絮视觉迭代时一并处理。
